Core Architecture & Features

Horizon Cloud Sync

Seamlessly sync your instances across devices using the headless Gens-Horizon cloud engine. Advanced Delta Sync technology analyzes files and downloads only the missing bits, dramatically reducing update times.

Advanced Instance Management

Create and manage Vanilla, Forge, Fabric, Quilt, or NeoForge instances instantly. Includes automated Java detection and downloader mechanisms to ensure compatibility.

Integrated Mod Browser

Search, download, and update mods, resource packs, and shaders directly from Modrinth and CurseForge without leaving the application.

Enterprise-Grade Security

Engineered with strict Electron context isolation and IPC safety. Microsoft credentials are encrypted using AES-256-GCM, and file integrity is verified via SHA1 hashing.

Total Customization

Personalize your experience with dynamic themes, custom wallpapers, and Mica blur effects. Animation toggles are available for low-end hardware optimization.

Native OS Integration

Deep integration with Windows Jump Lists for quick launching, and an official signed APT repository for automated updates on Debian and Ubuntu systems.

Microsoft Multi-Account

Securely authenticate and switch between multiple Microsoft accounts. Fully supports offline mode with automated fallback mechanisms when no connection is detected.

Discord Rich Presence

Automatically broadcasts the instance you are currently playing to your Discord profile, integrated efficiently to preserve system resources.

Linux (Debian / Ubuntu APT)

Install securely using our signed APT repository for automatic background updates:

# 1. Add the trusted signing key
curl -fsSL https://williambossard.github.io/Gens-Launcher/public.key | sudo gpg --dearmor -o /usr/share/keyrings/gens-launcher-keyring.gpg

# 2. Add the repository to your sources
echo "deb [signed-by=/usr/share/keyrings/gens-launcher-keyring.gpg] https://williambossard.github.io/Gens-Launcher/ ./" | sudo tee /etc/apt/sources.list.d/gens-launcher.list

# 3. Install!
sudo apt update && sudo apt install gens-launcher

Frequently Asked Questions

Does Gens Launcher support cracked / offline accounts?

+

Yes! While we highly encourage using official Microsoft accounts for the best and most secure experience, Gens Launcher includes built-in support for offline accounts allowing you to play locally.

Why does Windows show a "Windows protected your PC" blue screen?

+

Because Gens Launcher is an independent, open-source project without a costly enterprise signing certificate. The installer is perfectly safe. Simply click "More info" and then "Run anyway".

How does Horizon Cloud Sync work?

+

It uses advanced Delta Sync technology. Instead of redownloading your entire 500MB modpack every time there is a small change, it analyzes the bytes locally and only downloads the specific 2MB that actually changed. It's incredibly fast.

Is it completely free?

+

Yes, Gens Launcher is 100% free, open-source under the MIT license, and contains absolutely zero telemetry or trackers. You are in full control of your data.
